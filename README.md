## Cómo usarlo

- Abre el README del módulo y selecciona una actividad.
- Sustituye las instrucciones de la plantilla por tu trabajo.
- Incluye evidencias sanitizadas: no publiques contraseñas, tokens, claves privadas, datos personales ni información sensible.
- Añade referencias y explica el alcance, las limitaciones y los resultados.
- Utiliza únicamente sistemas propios o entornos donde tengas autorización explícita para realizar pruebas.

**Estado:** estructura inicial y plantillas; no representa actividades completadas ni resultados de auditorías reales.
