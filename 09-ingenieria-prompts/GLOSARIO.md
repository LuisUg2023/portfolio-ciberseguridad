# Glosario técnico — Prompt Like an Engineer

| Término | Definición |
|---|---|
| AI (Artificial Intelligence) | Inteligencia artificial: sistemas capaces de realizar tareas asociadas con capacidades cognitivas humanas. |
| Chatbot | Aplicación que permite interactuar mediante conversaciones. |
| Prompt | Instrucción o entrada proporcionada al modelo para orientar una tarea. |
| Prompt Engineering | Diseño, estructuración y optimización de prompts para mejorar los resultados. |
| User Prompt | Mensaje o solicitud introducida por el usuario. |
| System Prompt | Instrucciones de alto nivel que establecen el comportamiento general del asistente. |
| Developer Instructions | Instrucciones del desarrollador que configuran el comportamiento de una aplicación basada en IA. |
| File Attachment | Archivo adjuntado a una conversación para ser procesado como fuente de información. |
| Context Window | Cantidad de información que el modelo puede considerar en una solicitud. |
| Conversation History | Mensajes previos que se incluyen como contexto de la interacción. |
| LLM (Large Language Model) | Modelo de lenguaje de gran escala entrenado para procesar y generar lenguaje. |
| Local LLM | Modelo de lenguaje ejecutado en un equipo o infraestructura local. |
| Inference | Proceso mediante el cual el modelo genera una salida a partir de una entrada. |
| Inference Latency | Tiempo que tarda el sistema en comenzar o completar la generación de una respuesta. |
| Tokens per Second | Medida de velocidad de generación de tokens por segundo. |
| Model Size | Tamaño del modelo, habitualmente expresado mediante su cantidad de parámetros y requisitos de memoria. |
| Parameters | Valores numéricos aprendidos durante el entrenamiento del modelo. |
| Quantization | Técnica que reduce la precisión numérica de los pesos para disminuir requisitos de memoria y cómputo. |
| Workflow | Flujo de trabajo: secuencia de tareas, personas y herramientas para alcanzar un objetivo. |
| Automation | Ejecución de tareas con intervención humana reducida. |
| Tool Calling | Capacidad de un modelo o asistente para solicitar la ejecución de herramientas externas. |
| Retrieval | Recuperación de información desde fuentes documentales o bases de conocimiento. |
| Prompt Injection | Ataque que intenta manipular al modelo mediante instrucciones maliciosas en entradas, documentos o contenido recuperado. |
| Hallucination | Generación de información incorrecta o no respaldada que puede presentarse como cierta. |
| Evaluation | Proceso de medir la calidad y confiabilidad de los resultados. |
| Human-in-the-Loop | Enfoque en el que una persona revisa, valida o autoriza decisiones del sistema. |
| Accuracy | Grado de corrección de un resultado respecto de una referencia válida. |
| Performance | Rendimiento del sistema en relación con calidad, tiempo y recursos utilizados. |
| Ground Truth | Referencia o conjunto de datos verificados utilizado para evaluar resultados. |
