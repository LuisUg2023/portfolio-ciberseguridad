# Cómo integrar documentos en el portafolio

1. Entra en el módulo correspondiente y abre la carpeta de la actividad.
2. Guarda el documento final en `entregables/` y las capturas sanitizadas en `evidencias/`.
3. Actualiza el README de la actividad: objetivo, alcance, procedimiento, herramientas, resultados, limitaciones y referencias.
4. Usa nombres descriptivos, por ejemplo `informe-auditoria-v1.pdf` o `captura-01.png`.
5. No publiques datos personales, información municipal sensible, direcciones IP públicas no autorizadas, credenciales, tokens, claves privadas ni datos reales de terceros.
6. Para laboratorios de seguridad, registra la autorización, el entorno, las fechas y las acciones realizadas.
