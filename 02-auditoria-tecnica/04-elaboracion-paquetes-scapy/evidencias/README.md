## Reglas de publicación

- Captura la pantalla completa o el área relevante, conservando el comando y su salida.
- Evita mostrar contraseñas, tokens, datos personales o información de redes ajenas al laboratorio.
- No alteres el contenido técnico de la captura.
- Si necesitas ocultar un dato sensible, conserva una copia original privada y publica únicamente una versión redactada, identificándola como tal.
- Registra en la práctica cualquier diferencia respecto del resultado esperado.
