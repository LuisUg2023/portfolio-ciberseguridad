# Módulo 1. Fundamentos de ciberseguridad

<badge>Estado: en desarrollo</badge>

## Objetivo general
Construir una base técnica para identificar activos, comprender amenazas y vulnerabilidades, aplicar principios éticos y reconocer controles y herramientas de seguridad.

## Caso práctico transversal
Se utilizará una **organización ficticia de servicios** que administra cuentas de clientes, equipos de trabajo, correo electrónico y una aplicación web. El escenario es académico: no se realizan pruebas contra sistemas reales ni se utilizan datos personales.

**Activos de referencia:** cuentas de usuario, estaciones de trabajo, aplicación web, base de datos, información de clientes y copias de seguridad.

## Actividades
1. [Marcos y controles](./01-marcos-controles/README.md): comparación de marcos y selección inicial de controles.
2. [Ética y uso responsable](./02-etica/README.md): autorización, privacidad, límites y manejo de evidencias.
3. [Amenazas, riesgos y vulnerabilidades](./03-amenazas-riesgos-vulnerabilidades/README.md): identificación y priorización de escenarios de riesgo.
4. [Herramientas de ciberseguridad](./04-herramientas/README.md): selección de herramientas defensivas y laboratorio seguro.
5. [Conocimientos y habilidades básicas](./05-habilidades-basicas/README.md): competencias técnicas y procedimiento de análisis.
6. [Herramientas y lenguajes de programación](./06-programacion/README.md): fundamentos de Python, consultas y automatización inicial.

## Criterios de calidad
- Explicar el propósito y alcance de cada actividad.
- Diferenciar hechos observados, supuestos y recomendaciones.
- Citar fuentes oficiales y registrar fecha de consulta.
- No publicar credenciales, tokens, datos personales ni información institucional.
- No declarar pruebas o resultados que no se hayan ejecutado y verificado.

## Relación con el certificado
Este módulo organiza contenidos introductorios de ciberseguridad y los convierte en evidencias de aprendizaje para un portafolio. No reproduce material protegido ni sustituye las evaluaciones oficiales de Coursera.
