# 03. Casos de uso de Splunk

**Duración:** 8 minutos.

## Objetivo
Relacionar machine data con necesidades de monitoreo, investigación y operación.

| Caso de uso del documento | Aplicación |
|---|---|
| Business Insights | Identificar patrones y generar inteligencia operacional. |
| Operational Visibility | Obtener visibilidad de extremo a extremo de la infraestructura. |
| Proactive Monitoring | Monitorear eventos y detectar problemas o ataques. |
| Search & Investigation | Correlacionar eventos e investigar patrones en grandes volúmenes. |
| Seguridad física | Analizar eventos de sistemas de seguridad física. |
| Seguridad de red | Investigar eventos de red; el documento cita listas de bloqueo mediante lookups. |
| Gestión de empleados | Ejemplo de clasificación o seguimiento mediante Knowledge Objects. |

## Escenario de laboratorio propuesto
Centralizar registros de autenticación de Linux, Windows y dispositivos de red para investigar intentos de acceso fallidos, identificar fuentes repetitivas y construir alertas.

Este escenario es una propuesta de práctica, no un laboratorio ejecutado ni un resultado observado.

## Preguntas de diseño
- ¿Qué fuentes producen los eventos?
- ¿Qué campos permiten correlacionarlos?
- ¿Qué retención se requiere?
- ¿Qué alertas necesitan atención inmediata?
- ¿Qué usuarios pueden consultar cada conjunto de datos?
