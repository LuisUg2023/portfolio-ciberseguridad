# 02. Splunk vs. ELK vs. Sumo Logic

**Duración:** 7 minutos.

## Objetivo
Identificar las plataformas comparadas y los criterios para evaluarlas.

| Plataforma | Elementos mencionados | Criterios de comparación |
|---|---|---|
| Splunk | Splunk Enterprise y Splunk Cloud | Ingesta, búsqueda, seguridad, operación, soporte y costo. |
| Elastic / ELK | Elasticsearch y Elastic Cloud | Almacenamiento, búsqueda, operación, escalabilidad y servicio gestionado. |
| Sumo Logic | Sumo Logic | Análisis de logs, operación cloud, integraciones y costos. |

## Criterios de evaluación
- Modelo de despliegue: local, cloud o híbrido.
- Volumen de ingesta y retención.
- Capacidades de búsqueda y correlación.
- Integración con fuentes de seguridad e infraestructura.
- Control de acceso y auditoría.
- Esfuerzo de administración y costo total.

El documento destaca la integración de Splunk para machine data, operaciones TI y seguridad, y menciona ELK y Sumo Logic como alternativas. No contiene métricas cuantitativas de rendimiento o costos; por eso no se asignan puntuaciones ni se declara un ganador.
